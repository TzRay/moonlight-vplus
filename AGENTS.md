# Project Memory

- `projects/sunshine` is the Sunshine source repository.
- `C:\Program Files\Sunshine` is the Sunshine installation path on this machine.
- Moonlight is the client application for game and desktop streaming. It connects to a compatible host and receives the streamed video, audio, and input session.
- Sunshine is the host/server application for game and desktop streaming. It runs on the machine being streamed from and exposes a GameStream-compatible service that Moonlight clients can connect to.
